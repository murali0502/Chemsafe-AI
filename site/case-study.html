The problem

A common name can point to several records. A mistyped CAS number can make the wrong record look like a plausible match. The workflow helps users confirm the substance and carry the source into a report they can share.

Implementation decisions

Confirm the identity first
Accept names and IUPAC aliases. Check CAS digits, use exact CAS matches, and require a source selection when records disagree.
Carry the evidence into the report
Show the dataset revision and the recorded labels. Attach a manufacturer SDS to the report when the user selects the exact product from the approved catalog.
Evaluate the model before showing its output
The liquids model found 232 of 340 positive test labels. The solids model missed all 29 positives and matched the majority-class baseline, so its predictions stay out of assessments.
Keep the deployment simple
Python prepares the pinned SafeChem data and model outputs at build time. Netlify serves the browser app, including search and downloads, without a separate Python service.
